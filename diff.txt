## 代码块 1：训练侧——“no-speak 消融”变体的定义

`streaming_reformat/encoded_interleave.py:66-88`：

```python
#: No-SPEAK ablation toggle (1h-no-speak). Read once at import from
#: ``DUPLEX_SPEAK_SUPERVISED`` (default ``1`` = true = emit <|speak|> as normal).
#: When disabled (``0``), the explicit <|speak|> transition is removed. The
#: former one-chunk-earlier text shift (collapse LISTEN→SPEAK→TEXT into
#: LISTEN→TEXT) ...
#: Used together with ``DUPLEX_IDLE_SUPERVISED=0`` (no <|idle|>) for the
#: 1h-no-speak cell. ...
#: _assign_speak_chunks is still gated off entirely under _NO_SPEAK as a belt-
#: and-suspenders guarantee that no <|speak|> is ever placed.
_NO_SPEAK: bool = os.environ.get("DUPLEX_SPEAK_SUPERVISED", "1").lower() in (
    "0", "false", "no", "off", "",
)
```

**翻译**：这个训练框架有个开关 `DUPLEX_SPEAK_SUPERVISED=0`（叫"1h-no-speak"消融）：关掉后 `<|speak|>` 牌**彻底从语料里移除**（代码里双保险保证“no `<|speak|>` is ever placed”），原本的“听→亮牌→正文”坍缩成“**听→直接正文**”。注释里这个变体叫 **“1h cell”**——对照 13041 的训练 run 名 `1h_li_resp720_intr720`（1h、li=LISTEN+INTERRUPT），命名对上了。

## 代码块 2：引擎侧——vLLM 根本不解析 speak token

`vllm_omni/experimental/fullduplex/qwen3_omni/runtime.py:411-422`：

```python
# v2_listen: when the agent-text decode target is the <|listen|>
# token (assistant silent this chunk), treat it as a listen decision
# rather than a speak with empty text. The model is supervised to
# emit <|listen|> for silent chunks (mim_omni/streaming_reformat).
listen_id = _special_token_id(sources, "<|listen|>")
decoded_listen = bool(token_ids) and (
    token_ids[-1] == listen_id ...
)
native_decision = "listen" if decoded_listen else "speak"   # ← 全部逻辑在这一行
```

**翻译**：引擎判断“模型在不在说话”的全部逻辑就是这一行——**输出是 `<|listen|>` 就算听，不是就算说**。引擎从头到尾没有一行代码去解析 `<|speak|>`（id 151698 在引擎里没有任何 special-case）。“speak”只是个推导出来的状态名，不是 token。

## 代码块 3：引擎侧——为这个 1h 消融专门写的适配

`omni_ar_scheduler.py:414-423`：

```python
if os.environ.get("QWEN3_OMNI_EMPTY_ACTION_BLOCK", "") == "1":
```

**翻译**：引擎里专门有个环境变量伺候“1h LISTEN+INTERRUPT 消融”系的 ckpt——注释直呼其名。vLLM 引擎和 1h 系训练格式是**互相认识**的。
